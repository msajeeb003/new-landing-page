EurekaEDU — scholarship finder

A scholarship platform for international students. An n8n and Google Gemini pipeline collects the listings; students search, compare, practise IELTS and plan their student visa in one place.

Live demo (opens in a new tab)See on Upwork (opens in a new tab)

The problem

Students who want to study abroad on a scholarship have to piece their plan together from dozens of websites: scholarship listings, university entry requirements, English test scores and embassy rules, often out of date or misleading. EurekaEDU puts all of it in one place, so a first-time applicant can find a scholarship they qualify for, see exactly what it takes and apply without paying an agent.

What EurekaEDU does

  • A scholarship finder that filters by country, study level (bachelor to PhD, diploma and language courses), funding type and the highest IELTS score the student can reach, including scholarships that accept MOI instead of IELTS or TOEFL.
  • Side-by-side comparison of programs, sorted by the nearest deadline. Each listing shows the funding, the deadline and the exact test requirement, and links to the official source.
  • University and degree pages, plus a visa and documents roadmap for the student's home country and embassy.
  • Free IELTS practice: auto-scored reading tests, and writing tasks with an AI band estimate, criterion-by-criterion feedback and a model answer.
  • Free accounts with a dashboard to save scholarships, set a target country, track deadlines and work on a CV.
  • Paid one-to-one consultations in 30, 60 and 90-minute packages, booked from the site.

Tools used

Next.js 15 (App Router, Server Components and Server Actions) with React 19 and TypeScript; Supabase for the PostgreSQL database and sign-in; Tailwind CSS and Framer Motion for the interface. n8n runs the data pipeline and Google Gemini turns raw scholarship pages into structured records. Zod validates every form and API request, and DOMPurify cleans any HTML content. It is deployed on Vercel.

How I built it

The listings come from an automated pipeline instead of manual data entry. On a schedule, an n8n workflow pulls scholarships from official national scheme sources, scholarship aggregators and news feeds. Google Gemini extracts the title, deadline, funding and requirements as structured JSON, each record is validated on its own, and the results are posted to a webhook protected by a shared secret. Valid listings publish automatically, so the site stays current without anyone typing them in, and a built-in admin CMS can edit any listing, publish drafts and retire expired scholarships.

Security is part of the design. Row Level Security on every database table means the public can only read published listings and each user can only see their own saved items. Middleware guards the dashboard and admin areas, the admin role is checked again on the server for every action, and secret keys never reach the browser.

Result

EurekaEDU is live. Students can search and compare scholarships, browse universities and degree programs by country, practise IELTS and plan their visa steps without an account. Signing up adds saved scholarships, an application journey tracker and a CV builder.
